# Варианты агентного взаимодействия — обзор и выбор

Короткая карта: чем агенты могут говорить друг с другом, что из этого у нас
уже есть, и когда что брать.

## 1. Hub-блэкборд по HTTP (наш текущий; по умолчанию)

Общая доска (messages / progress / world / events) + SSE на дашборд;
`FileBoard` рядом, `HttpBoard` через сеть ([distributed.md](distributed.md)).

- **+** переживает плохой WiFi (best-effort записи, ретраи чтений); один
  источник правды; чат = артефакт запуска (можно перечитать/переиграть);
  протокол фаз навязывается кодом, а не промптом.
- **−** цикл опроса (секунды латентности), координатор — единая точка отказа.
- **Вердикт: остаётся базой.** Всё остальное — надстройки над той же доской.

## 2. MCP-инструменты (PicoClaw-путь; готово к пробе)

Мозг — произвольный агент (PicoClaw/Claude/кастом), робот и доска — MCP-тулзы
(`drone/picoclaw_bridge_mcp.py`: полётные + read_board / post_message /
report_progress / emit_thought). Тест: `tests/test_picoclaw_shim.py`,
протокол-промпт: `souls/picoclaw-pilot.md`.

- **+** мозг заменяется без правок стека; в чатах разницы нет — те же
  messages/events, дашборд не отличит.
- **−** дисциплина фаз держится на промпте: свободный агент может нарушить
  протокол (пропустить CLAIM, полететь в чужую зону). Смягчение: доска
  отвергает то, что нарушает контракт (уже частично так — hub 409).
- **Вердикт: пилотировать на test-3x3** (1 борт, узкий протокол), не на city.

## 3. A2A (Agent2Agent, Google 2025) / ACP

Межагентный HTTP-протокол: карточки возможностей, task-делегирование.
Красиво для федерации разных вендоров; для роя на одном поле — лишний слой
поверх того, что доска уже делает. **Вердикт: не сейчас.**

## 4. ROS2-топики как шина агентов

Агенты говорят напрямую через DDS (общие топики/сервисы).
- **+** нативно для роботов, миллисекундная латентность.
- **−** DDS-discovery по WiFi между бортами — известная боль; чат нечитаем
  оператору без моста; LLM-агенту всё равно нужен HTTP/py-мост.
- **Вердикт: только внутри борта** (как сейчас: bridge_node ↔ PX4), не между.

## 5. Групповой чат «все говорят со всеми» (AutoGen-стиль)

Свободная беседа N агентов без фазовой машины.
- **+** максимально живые споры (то, что хочется видеть в демо).
- **−** без арбитра разговор расходится; на реальном железе это риск.
- **Вердикт: взять кусочек** — наш scan_debate уже так устроен (DEBATE_ROUNDS
  раундов свободного спора), но полёт остаётся за фазовой машиной. Расширять
  спор (больше раундов, больше пилотов) — да; отдавать ему управление — нет.

## Итог

База — доска (1). PicoClaw/MCP (2) — включаем как сменный мозг на test-3x3.
A2A/ROS2-шина (3, 4) — не тащим. Из группового чата (5) берём драматургию
спора, не отдавая ему фазовую машину.
