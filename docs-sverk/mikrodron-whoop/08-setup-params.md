# Загрузка параметров


Во вкладке **Parameters** находятся все настройки полётного контроллера, но без графического интерфейса.


*Загрузите базовый [файл параметров](https://drive.google.com/drive/folders/1aVPsCSyAKYzgZ8UkZjKGdlTMvxZDnppT?usp=drive_link), который содержит большую часть настроек. Однако некоторые параметры (такие как калибровка датчиков, аппаратуры управления и питания) требуют ручной настройки, так как зависят от физического состояния датчиков IMU и аппаратуры управления и могут меняться.*


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-flight-controller%2Fimage7.png&sig=66529f5bc0c5bcfe12e4c8626de4eb5576464ff8f9771bf67613eb03d04adcdf)


- Нажмите кнопку **Tools**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-flight-controller%2Fimage2.png&sig=e7009fafbdc2117f1c0f77fed5575923b44c8db376e9e4e88b418013163bae42)


- В открывшемся окне выберите **Load from file for review**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-flight-controller%2Fimage3.png&sig=53451d5d90dc97938ef4a1742cce0d68e4f10c0fbe818db4acde7f3f946a6646)
