# Настройка озвучки RadioMaster Pocket


Скачайте [архив настроек](https://drive.google.com/drive/folders/13V-xxbfMj9bZtWU3VrE0vCBnuwDvGQ82?usp=drive_link) аппаратуры управления. Архив содержит следующие файлы:

|  Файл |  Описание |
|  model00.yml |  Профиль настроек для управления микродроном |
|  radio.yml |  Настройки передатчика (аппаратуры управления) |
|  ru |  Архив русской озвучки |


## Копирование файлов

- Подключите аппаратуру управления к компьютеру через верхний разъём USB-C с помощью USB-кабеля.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-controller%2Fimage14.png&sig=9015dfdd2b7665c4c6fc88efc92c605cfc5572b41ffffdfd69694ccf3bc91030)


- В появившемся окне на экране аппаратуры управления выберите **USB Storage (SD)**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-controller%2Fimage19.png&sig=437b4b5173ba1a79c1c001eba2d78009e7d1da31ccc5cc12735fe405ef305ede)


- Откройте хранилище аппаратуры управления, в папку **MODELS** скопируйте файл *model00.yml*.

>

**Внимание** Если в папке уже есть файл с таким названием — удалите его или согласитесь на замену.


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-controller%2Fimage5.png&sig=103e1876ab353267a8945eba0474b1ba7b155c7d459cade0590279f88a06fa4b)


- В папку **RADIO** скопируйте файл *radio.yml*.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-controller%2Fimage1.png&sig=8fd347722fcb6ff20fa6ca678bbf4ecf8795f63bfa96a460cf030d17493b75ca)


- В папку **SOUNDS** скопируйте папку *ru*.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-controller%2Fimage27.png&sig=dd7280bacd8705fc7c3205fe3befe0308d44a592b8a4427e3589d0986162df6c)


- Отключите аппаратуру управления от компьютера.

## Применение русской озвучки

- Нажмите кнопку **SYS**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-controller%2Fimage15.png&sig=211d030065825df2d26f88168b99021a75203bae999107929ed5d916ef41756d)


-

С помощью кнопки **PAGE>** перейдите в третью вкладку **RADIO SETUP**.

-

Пролистайте до **voice language** и выберите **Russian**.
