# Настройка питания


*Перед настройкой питания убедитесь, что воздушные винты не установлены на моторах.*


Во вкладке **Power** настраиваются параметры [АКБ](/learn/whoop/kb-battery).


>

**Внимание** Обращайте внимание на маркировку АКБ — сверьтесь с [таблицей напряжений](/learn/whoop/kb-battery#2-%D0%BD%D0%B0%D0%BF%D1%80%D1%8F%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5-%D1%8F%D1%87%D0%B5%D0%B5%D0%BA-%D1%82%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D0%B0-%D0%B7%D0%BD%D0%B0%D1%87%D0%B5%D0%BD%D0%B8%D0%B9) перед настройкой.


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-power%2Fimage1.png&sig=9ee2097ed0a8129d9881904ebb51a343be140ed72fc1d8050f619b807be79528)


-

Установите параметр **Number of cells** в соответствии с количеством ячеек в АКБ (для АКБ из комплекта — **1S**).

-

Установите параметр **Empty Voltage** (минимальное напряжение для ячейки АКБ) значение **3.55V** (для LiHV АКБ).

-

Установите параметр **Full Voltage** (максимальное напряжение для ячейки АКБ) значение **4.35V** (для LiHV АКБ).


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-power%2Fimage5.png&sig=cc146e10cd729e9f537149ea59eeb5eb0dbd76cb0afa2101fc274eafa99c8524)



**Проверка**


После настройки перейдите на вкладку **Summary**. Все пункты должны быть отмечены зелёным маркером.
