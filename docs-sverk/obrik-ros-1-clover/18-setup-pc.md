# Работа с полем ArUco-маркеров


В комплектации идёт готовая распечатанная карта меток, которая записана в систему бортового компьютера при установке образа.


Её можно использовать, чтобы проверить корректность работы всей системы, совершить автономный взлёт и посадку.

Убедитесь, что вы подключены к Обрику и открыт веб-интерфейс (см. [Веб-интерфейс](/learn/clover-2/web-interface)).


## Проверка ArUco-карты


В веб-интерфейсе перейдите в раздел **View image topics** и выберите топик `aruco_map/image`. Проверьте, какая ArUco-карта загружена на Обрик.

## Команды генерации файла карты ArUco-маркеров


>

**Hint** Подробности описаны в статье [«Навигация по картам ArUco-маркеров»](/learn/clover-2/aruco-map)


Для создания файла карты необходимо выполнить команду с заданными параметрами.


Определите следующие значения для вашей карты:

- `length` — длина стороны маркера в метрах (например, 0.3)
- `x` — количество маркеров по оси X (столбцов)
- `y` — количество маркеров по оси Y (строк)
- `dist_x` — расстояние между центрами маркеров по оси X (м)
- `dist_y` — расстояние между центрами маркеров по оси Y (м)
- `first_ID` — ID первого маркера
- `--top-left` — нумерация с верхнего левого угла (стандарт для большинства полей)

### Выполните команду генерации

-

В терминале выполните следующую команду, подставив свои параметры:


```
rosrun aruco_pose genmap.py <length> <x> <y> <dist_x> <dist_y> <first_ID> > ~/catkin_ws/src/sverk/aruco_ws/src/sverk/aruco_pose/map/<Имя_файла>.txt --top-left

```


>

**Hint** Стандартное имя файла карты — `map.txt`. Если вы укажете другое имя при генерации, его необходимо прописать в конфигурационном файле `aruco.launch` (параметр `<param name="map" value="$(find aruco_pose)/map/ВАШ_ФАЙЛ.txt"/>`)


Настройка ROS-ноды для работы с новой картой:

-

Откройте конфигурационный файл:


```
nano ~/catkin_ws/src/sverk/sverk/launch/aruco.launch

```

-

Найдите строку с параметром `map` и замените имя файла:


```
<arg name="map" default="map.txt"/>

```


На:


```
<arg name="map" default="sverk.txt"/>

```

-

Сохраните изменения: `Ctrl`+`X`, затем `Y`, затем `Enter`


>

**Note** `aruco.launch` — файл запуска ROS для детектирования ArUco-меток. Он запускает узлы, которые принимают изображения с камеры, обрабатывают их и публикуют координаты меток в реальном времени.


### Пример генерации карты ArUco-меток


Параметры для генерации из примера:

- `length` — 0.3 (длина стороны маркера, м)
- `x` — 3 (столбцов)
- `y` — 2 (строк)
- `dist_x` — 0.5 (расстояние между центрами по X, м)
- `dist_y` — 0.5 (расстояние между центрами по Y, м)
- `first_ID` — 42

Команда генерации:


```
rosrun aruco_pose genmap.py 0.3 3 2 0.5 0.5 42 > ~/catkin_ws/src/sverk/aruco_pose/map/sverk.txt --top-left

```


>

**Hint** Поскольку первая метка — №42, карта сгенерируется с метками по возрастанию: 42, 43, 44, 45, 46, 47. Если ваши номера отличаются — отредактируйте файл вручную (см. ниже).


### Редактирование карты ArUco-меток


Размер метки для взлёта должен составлять **1.5×1.5 см**.


>

**Note** Для удобства добавляйте метку 1.5×1.5 см на свои карты.

-

Откройте файл с помощью команды:


```
nano ~/catkin_ws/src/sverk/aruco_pose/map/sverk.txt

```

-

Внесите изменения — поменяйте первый столбец (ID меток) и размер первой метки для взлёта:


>

**Hint** Для перемещения внутри файла используйте стрелки на клавиатуре.

-

Сохраните и выйдите: `Ctrl`+`X`, `Y`, `Enter`

-

Перейдите в папку с конфигурационными файлами:


```
cd ~/catkin_ws/src/sverk/sverk/launch/

```

-

Откройте файл `aruco.launch`:


```
nano aruco.launch

```

-

Найдите строку с путём к файлу карты и замените `map.txt` на `sverk.txt`

-

Сохраните и выйдите: `Ctrl`+`X`, `Y`, `Enter`

-

Для применения изменений перезагрузите сервис:


```
sudo systemctl restart sverk.service

```


Проверьте вид сгенерированной карты — в веб-интерфейсе перейдите в раздел **View image topics (web_video_server)**

-

Откройте топик `/aruco_map/image`
