# Глоссарий


## АКБ


Аккумуляторная батарея. Источник питания дрона.


## Аппаратура управления


Основное устройство для ручного управления дроном. В комплекте — RadioMaster Pocket.


## ArUco-метка


Квадратный графический маркер с чёрно-белым бинарным рисунком. Используется системой машинного зрения для определения положения коптера в пространстве.


## Бортовой компьютер/Raspberry Pi


Вычислительный модуль на базе Raspberry Pi, установленный на дрон. Отвечает за работу высокоуровневых систем: машинное зрение, сеть, выполнение автономных миссий. [Популярный одноплатный микрокомпьютер](/learn/clover-2/raspberry), использующийся в Обрике.


## Трансляция видео


Передача видеопотока с камеры на наземную станцию или в веб-интерфейс.


## ExpressLRS


Протокол высокоскоростной и помехоустойчивой радиосвязи с малой задержкой, используемый для передачи команд с аппаратуры управления на коптер.


## Калибровка


Процедура настройки и выравнивания показаний датчиков коптера (гироскоп, акселерометр, компас) или органов управления.


## MAVLink


Протокол обмена сообщениями между компонентами дрона (полётным контроллером, бортовым компьютером, наземной станцией).


## Полётный контроллер (ПК)


“Мозг” коптера. Устройство, отвечающее за стабилизацию, обработку данных с датчиков и выполнение полётных задач. Автопилот — его основная функция.


## Прошивка (файл)


Файл с программным обеспечением для полётного контроллера или модуля ExpressLRS.


## Прошить (действие)


Процесс установки или обновления программного обеспечения на полётном контроллере или модуле ExpressLRS.


## QGroundControl (QGC)


Наземная станция управления (Ground Control Station). Программа для настройки, калибровки, планирования миссий и мониторинга.


## ROS (Robot Operating System)


Мета-операционная система и набор ПО для управления сложными робототехническими системами. Используется на бортовом компьютере.


## Светодиодная лента (LED)


Индикатор состояния дрона, установленный на раме.


## Сопряжение (биндинг)


Процесс создания защищённой радиосвязи между передатчиком (TX) аппаратуры управления и приёмником (RX) по протоколу ExpressLRS.


## Стик


Орган управления на аппаратуре управления. Левый стик (по умолчанию Mode 2) — газ/рыскание. Правый стик — крен/тангаж.


## Тумблер/Переключатель


Орган управления на аппаратуре управления (SA, SB, SC, SD). Используется для активации функций (Arm, полётные режимы, kill-switch).


## Квадрокоптер


Беспилотный летательный аппарат с 4-мя винтами и электронной системой стабилизации.


## Мультикоптер/коптер


Беспилотный летательный аппарат с электронной системой стабилизации и числом винтов, равным 3 (трикоптер), 4 (квадрокоптер), 6 (гексакоптер), 8 (октокоптер) или более.


## Мотор


Электродвигатель, который вращает винты мультикоптера. Обычно используются бесколлекторные электродвигатели. Такие двигатели подключаются к ESC.


## ESC/регулятор двигателя/“регуль”


Electronic Speed Controller. Специализированная плата, которая управляет скоростью вращения бесколлекторного электродвигателя. Управляется полётным контроллером при помощи широтно-импульсной модуляции (ШИМ).


ESC имеет прошивку, которая определяет особенности его работы.


## Телеметрия


Система для передачи данных о состоянии аппарата или команд для него по воздуху. Примеры: радиомодемы (RFD900, 3DR Radio Modem), Wi-Fi модули (ESP-07). Raspberry Pi также может быть использован в качестве модуля для телеметрии: [использование QGroundControl через Wi-Fi](/learn/clover-2/connect-wi-fi).


## Арминг


Armed – состояние коптера готовности к полёту. При поднятии стика газа либо при посылке внешней команды с целевой точкой – коптер полетит. Обычно коптер начинает вращать винтами при переходе в состояние “armed” даже если стик газа находится внизу.


Противоположным состоянием является Disarmed.


## PX4


Популярное программное обеспечение автопилота с открытым исходным кодом, работающее на платах Pixhawk, Pixracer и других.


## Образ SD-карты


Полная копия содержимого SD-карты, представленная в виде файла. Такой файл можно загрузить на SD-карту, воспользовавшись специальной утилитой, например Etcher. SD-карта, вставленная в Raspberry Pi является единственным его долговременным хранилищем и полностью определяет, что он будет делать.


## MAVROS


Библиотека - связующее звено между аппаратом, работающем по протоколу MAVLink, и ROS.


## UART


Последовательный асинхронный интерфейс передачи данных, применяемый во многих устройствах. Например, GPS антенны, Wi-Fi роутеры или Pixhawk.


## IMU


Inertial measurement unit. Комбинация датчиков (гироскоп, акселерометр, магнитометр), которая помогает коптеру рассчитывать ориентацию и положение в пространстве.


## Estimation


Процесс определения ПО полётного контроллера состояния квадрокоптера: положения в пространстве, скоростей, углов наклона и т. д. Для этого используется смешивание данных с установленных датчиков и различные алгоритмы фильтрации, например [фильтр Калмана](https://ru.wikipedia.org/wiki/%D0%A4%D0%B8%D0%BB%D1%8C%D1%82%D1%80_%D0%9A%D0%B0%D0%BB%D0%BC%D0%B0%D0%BD%D0%B0).


В прошивке PX4 для estimation’а используется модуль [ECL EKF](https://docs.px4.io/main/en/advanced_config/tuning_the_ecl_ekf.html) (EKF2).


## Failsafe


Автоматическая реакция полётного контроллера на аварийную ситуацию: потерю радиосвязи, критически низкое напряжение АКБ и т. д. Настраивается в QGroundControl. Типичные действия: посадка, зависание на месте или возврат домой (RTL).


## frame_id


Идентификатор системы координат в сообщениях ROS (например, `map`, `odom`, `base_link`, `body`). Определяет, в каком пространстве заданы координаты. Подробнее — в статье [Системы координат](/learn/clover-2/frames).


## OFFBOARD


Режим полёта PX4, при котором команды управления поступают от внешнего компьютера (бортового компьютера) по протоколу MAVLink/MAVROS. Используется для [автономных полётов](/learn/clover-2/offboard-flight).


## Optical Flow


Программный модуль, вычисляющий горизонтальную скорость дрона по смещению изображения с камеры. Позволяет удерживать позицию без GPS. На Обрике реализован средствами ROS.


## POSCTL (Position mode)


Режим полёта PX4, при котором коптер удерживает горизонтальное положение и высоту, реагируя на отклонения стиков. Требует надёжного источника позиции (GPS или Optical Flow).


## Selfcheck


Утилита `rosrun sverk selfcheck.py`, выполняющая автоматическую проверку готовности дрона к автономному полёту: доступность сервисов, наличие необходимых топиков, параметры PX4 и статус [MAVROS](/learn/clover-2/mavros).


## SSH


Secure Shell — протокол зашифрованного удалённого доступа к командной строке Raspberry Pi. Используется для настройки и отладки дрона. Подробнее — в статье [Подключение по SSH](/learn/clover-2/ssh).
