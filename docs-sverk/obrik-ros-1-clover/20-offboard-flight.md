# Программирование автономных полётов


Платформа Обрика использует [Raspberry Pi](/learn/clover-2/raspberry) для программирования автономных полётов дрона. Основной язык — Python. Программа может [получать телеметрию](/learn/clover-2/commands-offboard-flight#get_telemetry) (напряжение АКБ, ориентацию, положение, скорости) и отправлять команды, например: [полететь в точку](/learn/clover-2/commands-offboard-flight#navigate), установить ориентацию и угловую скорость.


Платформа основывается на [фреймворке ROS](/learn/clover-2/ros), который обеспечивает связь между пользовательской программой и сервисами. Для связи с полётным контроллером используется пакет [MAVROS](/learn/clover-2/mavros).


Для автономного полёта в PX4 используется режим OFFBOARD. API переводит дрон в этот режим автоматически. В случае необходимости прерывания автономного полёта переведите дрон в любой другой режим с помощью переключателя режимов на пульте.


## Системы позиционирования


Для того чтобы дрон мог зависать на месте или летать между точками, необходимо использование системы позиционирования — она вычисляет и сообщает дрону, где он находится. Обрик поддерживает несколько систем позиционирования:


### Optical flow


Принцип работы optical flow основан на вычислении сдвигов между соседними кадрами с камеры и передаче этой информации в полётный контроллер для расчёта смещения дрона относительно начальной точки. Используется [камера](/learn/clover-2/camera) и [лазерный дальномер](/learn/clover-2/laser).


Подробности — в статье [Optical Flow](/learn/clover-2/optical-flow).


### ArUco-маркеры


Технология визуальных маркеров позволяет рассчитать позицию дрона относительно распознанных маркеров и передать эту информацию в полётный контроллер. Используется камера и маркеры, наклеенные на пол или потолок.


Подробности — в статье [Визуальные маркеры](/learn/clover-2/aruco).


## Автономный полёт


>

**Info** Для изучения языка программирования Python можно обратиться к [самоучителю](https://pythonworld.ru/samouchitel-python).


После настройки системы позиционирования становится возможным написание скриптов для автономных полётов. Для выполнения скриптов [подключитесь к Обрику по SSH](/learn/clover-2/ssh).


Перед первым полётом рекомендуется проверить конфигурацию Обрика с помощью [утилиты selfcheck.py](/learn/clover-2/automatic-check):


```
rosrun sverk selfcheck.py

```


Для того чтобы запустить Python-скрипт, используйте команду `python3`:


```
python3 flight.py

```


Пример программы для полёта (взлёт, пролёт вперёд, посадка):


```
import rospy
from sverk import srv
from std_srvs.srv import Trigger

rospy.init_node('flight')

get_telemetry = rospy.ServiceProxy('get_telemetry', srv.GetTelemetry)
navigate      = rospy.ServiceProxy('navigate', srv.Navigate)
land          = rospy.ServiceProxy('land', Trigger)

# Взлёт на высоту 1 м
navigate(x=0, y=0, z=1, frame_id='body', auto_arm=True)

# Ожидание 3 секунды
rospy.sleep(3)

# Пролёт вперёд 1 метр
navigate(x=1, y=0, z=0, frame_id='body')

# Ожидание 3 секунды
rospy.sleep(3)

# Посадка
land()

```


>

**Note** Функция `navigate` не ожидает, пока дрон долетит до целевой точки — скрипт продолжит выполнение сразу. Для блокирующей версии смотрите функцию [`navigate_wait`](/learn/clover-2/commands-offboard-flight#%D1%84%D1%83%D0%BD%D0%BA%D1%86%D0%B8%D1%8F-navigate_wait-%D0%BF%D0%BE%D0%BB%D1%91%D1%82-%D0%B2-%D1%82%D0%BE%D1%87%D0%BA%D1%83-%D1%81-%D0%BE%D0%B6%D0%B8%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5%D0%BC).


Обратите внимание, что параметр `auto_arm=True` устанавливается только у первого вызова `navigate`. Он армит дрон и переводит его в режим OFFBOARD.


Параметр `frame_id` задаёт систему координат, относительно которой задаётся целевая точка:

- `body` — связана с корпусом дрона;
- `navigate_target` — связана с предыдущей целевой точкой полёта;
- `map` — связана с локальной системой координат дрона;
- `aruco_map` — связана с картой ArUco-маркеров;
- `aruco_N` — связана с ArUco-маркером с ID=N.

Подробности — в статье [Системы координат](/learn/clover-2/frames). Полное описание API приведено в статье [Команды (OFFBOARD)](/learn/clover-2/commands-offboard-flight).


>

**Hint** В Обрике также доступна поддержка [блочного программирования](/learn/clover-2/blocks) автономных полётов.
