## 1. Что это за система

Рой агентов (координатор + 4 дрона + ровер) решает задачу через **общую доску**
(файлы на диске или HTTP-хаб). Поверх — **экономика**: агенты платят друг другу
по x402/AP2 на EVM или TON.

Три независимых подсистемы. Ломая одну, вы обычно не ломаете остальные:

```
агенты (agent/)  ──пишут──>  доска (blackboard)  ──читает──>  дашборд (viz/)
     │
     └──HTTP──> бридж (bridge/) ──> робот: мок | Gazebo | железо

платежи (payments/) ──> anvil/TON ──> эксплорер (:8090)
```

## 3. Инварианты — нарушать нельзя

**Единственный писатель.** Только координатор пишет `state/phase.json`,
`decision.json`, `assignments.json`, `world.json`. Остальные читают.

**Контракт бриджа стабилен.** `POST /photograph|/detect_obstacle|/navigate|
/move|/spray`, `GET /pose|/healthz`. Он одинаков для мока, симуляции и железа —
на этом держится переход сим → железо. Меняете контракт — меняете три
реализации сразу.

**Домен EIP-712 продублирован.** `EIP712("Sverk", "2")` в
`payments/contracts/src/SverkToken.sol` и `X402_EIP712_NAME`/`X402_EIP712_VERSION`
в `payments/ap2_policy.py:61`. Разъедутся — подписи перестанут проверяться, и
платежи упадут с невнятной ошибкой. Менять только вместе.

**Путь артефакта контракта.** forge кладёт в `out/<файл>.sol/<контракт>.json`.
Путь зашит в `pyproject.toml`, `payments/evm_bootstrap.py` и трёх тестах.
Переименование контракта — это правка всех пяти мест.

**Агенты без интернета.** Сеть `mesh` — `internal: true`. Реальной LLM нужен
оверлей `docker-compose.egress.yml`, иначе агенты молча уходят в шаблоны.

## 4. Ловушки, на которых уже теряли время

**`make payments-test` и `demo-*` начинают с `down -v`.** Они сносят тома.
Запуск теста поверх живого демо уничтожает демо, а на хакатоне — общую цепочку
у всех подключившихся. Для повторного прогона миссии есть `make mission-rerun`,
он цепочку не трогает.

**Compose склеивает списки портов, а не заменяет.** Оверлей без `!override`
даёт два бинда на один порт, и второй падает с «address in use». См.
`docker-compose.lan.yml`.

**Запуск compose руками без `LAN_BIND_IP`** меняет бинд → compose считает
определение anvil устаревшим → **пересоздаёт его и стирает цепочку**. Дефолт
специально `127.0.0.1`, чтобы ошибка закрывала доступ. Пользуйтесь make-целями.

**Порт 8080 занят.** Дашборд на `VIZ_HOST_PORT` (8095), хаб на `HUB_HOST_PORT`
(8096).

**Одинаковые `container_name`.** `docker-compose.distributed.yml` и основной
стек не поднимаются одновременно. Отдельное имя проекта (`-p`) не спасает —
`container_name` его игнорирует.

**`ip route get <внешний ip>` врёт при поднятом VPN** — отдаёт адрес туннеля.
Для адреса в локальной сети берите интерфейс явно.

**Правки фронта не видны.** Кэш браузера. `fetch(url,{cache:'reload'})` или
Ctrl+Shift+R. Сначала убедитесь `curl`-ом, что контейнер отдаёт новый файл.

**Рестарт бриджа без `pkill`** оставляет живым старый процесс — правки не
применяются.

**`SPAWN_X`/`SPAWN_Y`** обязаны совпадать с точкой спавна дрона. Дефолт `0`
уводит борт за поле и даёт серые пустые снимки.

## 5. Как проверять работу

Порядок от быстрого к медленному. Не объявляйте задачу сделанной, пока не
прошёл релевантный уровень.

```bash
python3 -m compileall -q agent bridge payments viz tests   # синтаксис
python3 -m unittest discover -s tests -p 'test_*.py'       # 76 тестов
make payments-test                                          # 182 + 76, в образе
make demo-survey                                            # миссия до PASS
make payments-demo                                          # 7 сделок RECEIPTED
make demo-distributed                                       # сетевой режим до PASS
```

Solidity-тесты в обычную сборку **не входят**: `Dockerfile.payments` копирует
только `src`, без `test/` и `node_modules`. Чтобы прогнать `forge test`, нужен
временный образ со стадиями зависимостей плюс `test/`.

Зависимости платежей (`web3`, `fastapi`, `eth_account`, …) живут только в
образе `archipelago-payments:local`. Локальный `python -m unittest` по
`payments/tests` даст ImportError — это не регрессия, гоняйте `make payments-test`.

Проверка живого стека без браузера:

```bash
curl -s localhost:8090/v1/explorer/chain      # токен, блок, символ
curl -s localhost:8090/v1/explorer/payments   # сделки и статусы
curl -s localhost:8095/messages               # сообщения миссии
ss -ltn | grep -E ':(8545|8090|8095)\s'       # на чём слушаем
```

Скриншоты страниц с SSE часто отваливаются по таймауту — рендерер занят
анимацией. Читайте `document.body.innerText` или `curl`.

## 6. Что сломано или не проверено

Прежде чем «чинить» эти места, прочитайте статус-файлы — там разбор причины.

* [agent/BLACKBOARD-STATUS.md](agent/BLACKBOARD-STATUS.md) — зелёные клетки не
  сбрасываются между прогонами (дефект фронта, `viz/survey.html:applyWorld`);
  `reset_runtime()` чистит по белому списку и пропускает новые файлы состояния.
* [bridge/ros2/BRIDGE-NODE-STATUS.md](bridge/ros2/BRIDGE-NODE-STATUS.md) —
  нода железа не гонялась вживую.
* Индексатор платежей: первая сделка может навсегда показывать
  `INTEGRITY_ERROR`. `payments/chain_indexer.py:249` снимает срез
  `["payment_receipt"]` до того, как приходит квитанция AP2, а курсор
  (`chain_indexer.py:139`) двигается только вперёд и этот блок больше не
  перечитывает. Живой `_integrity()` в `payments/explorer.py` считает
  правильно — расходятся именно замороженные данные.

## 8. Правила работы с этим репозиторием

**Секреты.** `.env` и `.env.ton` не коммитятся (`.gitignore: .env.*`). Мнемоника
TON — только testnet, режим 0600, в логи не печатается. Не выводите содержимое
`.env` в вывод команд.

**Каноническая мнемоника anvil** (`test test … junk`) публична и годится только
для локальной цепочки. Никогда не предлагайте её для чего-то настоящего.

**Капча фаусета TON не обходится.** Это записано и в `scripts/ton_faucet.py`.

**Перед сносом или перезаписью** посмотрите, что там лежит. Если файл писали не
вы и его содержимое расходится с описанием задачи — сообщите, а не
перезаписывайте.

**Отчитывайтесь честно.** Упавший тест — показать вывод. Пропущенный шаг —
сказать. Не объявлять готовым то, что не проверено.
