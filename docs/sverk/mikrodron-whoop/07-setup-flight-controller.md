# Настройка полётного контроллера

-

Убедитесь, что вставлена SD-карта.

-

Убедитесь, что микродрон [подключён по Wi-Fi](/learn/whoop/setup-wifi) и QGroundControl настроен для работы по UDP — см. [Подключение к QGroundControl](/learn/whoop/kb-qgc).


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-flight-controller%2Fimage8.png&sig=fb3e047b9bf70086c6e0908a152f09ae335e9b77b1d3459156e4c29e80d20163)


- Нажмите на **логотип QGC** в левом верхнем углу.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-flight-controller%2Fimage11.png&sig=e9d2fe7ae83bcd8f6325a7c6ec0f7303f9a48976e7b2e1415356169dece07cad)


- Выберите **Vehicle Configuration**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-flight-controller%2Fimage6.png&sig=35e8f0ca039bc510c238c34583ab20652917be58038afbc2792999eceb2b947e)



>

**Примечание** Вкладка **Summary** содержит информацию о выбранных настройках и состоянии систем (зелёный маркер — система настроена, красный маркер — не настроена).
