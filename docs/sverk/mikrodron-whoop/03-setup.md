# Предустановка программ и файлов


**Шаг 1. Установка программного обеспечения**


Для дальнейшей настройки и работы с микродроном установите следующие программы:

-

[QGroundControl](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/getting_started/download_and_install.html) — программное обеспечение для настройки и калибровки полётного контроллера. При установке дайте **согласие на установку** дополнительных драйверов.

-

SSH-клиент на ОС Windows (например, [mRemoteNG](https://mremoteng.org/)) для подключения к бортовому компьютеру и работы с нейросетью. Для macOS и Linux — Terminal (встроен в систему).


**Шаг 2. Скачивание файлов**


Создайте на рабочем столе папку, например, «Микродрон», и сохраняйте все файлы в неё.

-

[Архив настроек](https://drive.google.com/drive/folders/13V-xxbfMj9bZtWU3VrE0vCBnuwDvGQ82?usp=drive_link) аппаратуры управления — профиль модели, радионастройки и русская озвучка;

-

[Файл с параметрами](https://drive.google.com/drive/folders/1aVPsCSyAKYzgZ8UkZjKGdlTMvxZDnppT?usp=drive_link) полётного контроллера.


>

**Примечание** Бортовой компьютер микродрона поставляется с предустановленным образом. Если потребуется переустановка — см. [Установка образа](/learn/whoop/kb-image).
