# Калибровка датчиков


Во вкладке **Sensors** находятся пункты калибровки датчиков микродрона.


>

**Подсказка** От точности калибровки датчиков зависит качество полёта.


>

**Примечание** Для калибровки воспользуйтесь [подключением по проводу](/learn/whoop/setup-wire). QGC может выдать предупреждение — нажмите **Ok**.

## Калибровка гироскопа

- Выберите меню **Gyroscope**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage1.png&sig=d43b6bd983e406fe3be2867d9b06959b8ae1ca831d397b3b63334d54ae09662d)


-

Установите микродрон на ровную поверхность.

-

Нажмите **Ok**.


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage8.png&sig=d84c8ee6bda933960136e36c28cf80e274f03561488ee56295b898c1235c1c33)


- Дождитесь окончания калибровки.

Если калибровка успешна — рамка самолёта будет зелёной, снизу надпись *Completed*. При ошибке — повторите заново.


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage6.png&sig=67dda871a645de1103b940bd15a0e4a68ecfd587ae50b0eec15339fb185d227a)



## Калибровка акселерометра


>

**Примечание** При калибровке акселерометра необходимо устанавливать микродрон в каждую из указанных ориентаций и удерживать до световой индикации.

- Выберите меню **Accelerometer**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage9.png&sig=d7abdddab8a05076c3b1f2746340618cdf702f3d06c42985c843e124314d46df)


- Поставьте параметры **Autopilot Orientation**: Pitch 180°, Yaw 90° и нажмите **Ok**.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage13.png&sig=6638a189c1b037179f51083cefd48d99611ab19eb9d78430c23a3940052b5742)


- Установите микродрон на шасси до появления жёлтой рамки.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage7.png&sig=ef50b749575597ede0f63d7ff5a11e4d48d798460e788b2f1d5307613fbc0e8b)


- Держите микродрон неподвижно до появления зелёной рамки.

![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage2.png&sig=3b1df9962a04cdc1ecacd4f3fdcc4310f8674678b74a54ac723b043cb77c8ec9)


- Повторите для всех положений поочерёдно.

Если калибровка успешна — все 6 рамок будут зелёными, снизу каждой надпись *Completed*. При ошибке — калибровка сбросится, повторите заново.


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=whoop%2Fassets%2Fsetup-calibration%2Fimage12.png&sig=41bbce47edc7d20b16e44886d72eb848da8fe64abaf7b1a5d2d6e56950bd5429)
