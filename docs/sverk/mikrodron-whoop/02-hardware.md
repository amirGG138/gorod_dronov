# Аппаратная часть


Микродрон включает в себя следующие компоненты:

-

Двигатели с пропеллерами;

-

Регуляторы оборотов (ESC);

-

Полётный контроллер на PX4;

-

Встроенный приёмник ExpressLRS;

-

Wi-Fi антенна;

-

Плата распределения питания (PDB);

-

Понижающе-повышающий модуль питания;

-

Аккумуляторы (2);

-

Бортовой компьютер;

-

Камера;

-

Датчик оптического потока.
