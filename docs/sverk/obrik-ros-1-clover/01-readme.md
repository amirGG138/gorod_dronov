# Обрик


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2F%25D0%25BE%25D0%25B1%25D1%2580%25D0%25B8%25D0%25BA_%25D0%25BE%25D0%25B1%25D0%25BB%25D0%25B5%25D0%25B3%25D1%2587%25D0%25B5%25D0%25BD%25D0%25BD%25D1%258B%25D0%25B9_%25D0%25B8%25D0%25B7%25D0%25BE%25D0%25BC%25D1%2582%25D0%25B5%25D1%2580%25D0%25B8%25D1%258F.png&sig=f446834ad2b11db1287bf924c96749651089fa425e808cfb65effe43175189ee)



**«Обрик»** — это образовательная платформа программируемого квадрокоптера для обучения роевому взаимодействию, компьютерному зрению и автономной навигации, на базе популярных открытых компонентов с документацией и библиотеками.


Набор включает в себя полётный контроллер с прошивкой PX4, Raspberry Pi Compute Module 4 (CM4) с платой ввода-вывода в качестве управляющего бортового компьютера, модуль камеры для реализации полётов с использованием компьютерного зрения, а также набор датчиков. Вес платформы до 300 грамм, что делает дрон безопасным для использования в классах и лабораториях школ, колледжей и вузов.


Платформа «Обрик» также включает в себя преднастроенный образ для Raspberry Pi на основе [clover](https://github.com/CopterExpress/clover) с полным набором необходимого ПО для работы со всей периферией и программирования автономных полётов.
