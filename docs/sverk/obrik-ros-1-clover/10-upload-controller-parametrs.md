# Загрузка параметров


Во вкладке **Parameters** находятся все настройки полётного контроллера без графического интерфейса.


Загрузите базовый [файл параметров](https://drive.google.com/file/d/1oXUSC6eFqQdOReyK6MX7AvGgaQyNHEUr/view?usp=drive_link) — он содержит большую часть настроек. Однако некоторые параметры (калибровка датчиков, аппаратуры управления и питания) требуют ручной настройки, так как зависят от физического состояния датчиков и аппаратуры.


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F6.png&sig=b4a99e7a442f639ebcacfef8a2c1dbe331ca1e8d35cbac287c17fde71d58e33a)


-

Нажмите кнопку **Tools**


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F7.png&sig=dca19d3b6f45bdc09b11b4b045f04cc503d37621c93feb99fa41ae2acb6ef9fc)


-

В открывшемся меню выберите **Load from file for review**


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F8.png&sig=ddd33d326c2d43a4fb2a3a5a95639ec53bff6617eba9dd97a84dd7325ca5335d)


-

Выберите скачанный файл с параметрами полётного контроллера


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F9.png&sig=f65adecc314551cfb09dbafec1b6361e7f6dbbadbf9e2ce8ca0625359ab78db9)


-

Ознакомьтесь со списком заменяемых параметров и нажмите **Ok**


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F10.png&sig=bebacc8a29d837e2c616dfccc6d73350dea2c9fd49e2e672287a5ee4078d5005)


-

Перезагрузите Обрик — нажмите кнопку **Tools**, затем выберите **Reboot Vehicle**


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F11.png&sig=e0850ff3f263e1164aae4b725b39479a63b2ecd6c17987e791dcd93a8bb2fd00)

![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F12.png&sig=8b7461f4ac8f9c76b9ac0810cb0df219dd197bf25009740efdbbaf54cc3c602d)


-

Нажмите **Ok**
