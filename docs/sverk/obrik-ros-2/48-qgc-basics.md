# Работа с QGroundControl (QGC)


QGroundControl (QGC) — это программа для настройки и мониторинга полётного контроллера Обрика. Через неё можно посмотреть телеметрию, откалибровать датчики, обновить прошивку и задать параметры полёта.


Когда Обрик включён, QGC показывает всё, что происходит с полётным контроллером: ориентацию в пространстве, напряжение аккумулятора, режим полёта и сигналы с аппаратуры управления.


---


## Как подключиться


Обрик поддерживает два способа подключения к QGC:

- [Подключение по Wi-Fi](/learn/obrik-ros-2/qgc-wifi) — основной способ. Обрик создаёт точку доступа, вы подключаетесь к ней с компьютера.
- [Подключение по проводу (USB)](/learn/obrik-ros-2/qgc-usb) — резервный способ, если Wi-Fi не работает или недоступен.
