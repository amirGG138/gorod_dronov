# Настройка образа после установки


После записи образа на SD-карту и первого включения Обрика нужно сделать несколько настроек, чтобы дрон был готов к полётам и программированию.


После первого запуска нужно настроить следующие компоненты:

-

**Поле ArUco-маркеров** — специальные квадратные метки на полу, по которым дрон ориентируется в пространстве без GPS. Настройка объясняется в разделе [Работа с полем ArUco-маркеров](/learn/obrik-ros-2/aruco-field).

-

**Камера** — чтобы дрон видел эти метки, нужно правильно настроить камеру на борту. Инструкция находится в разделе [Настройка камеры](/learn/obrik-ros-2/camera-focus).

-

**Главный launch-файл** — все основные системы дрона (камера, ArUco, команды полёта, светодиодная лента, веб интерфейс) запускаются автоматически при включении одним launch-файлом. Как он устроен, как включать/выключать подсистемы и как применять изменения — в разделе [Главный launch-файл системы](/learn/obrik-ros-2/main-launch).
