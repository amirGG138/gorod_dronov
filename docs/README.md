## С чего начинать под конкретный вопрос

- **Что вообще требуется по задаче, баллы, ограничения** →
  [`reglament/gorod_dronov_reglament.md`](reglament/gorod_dronov_reglament.md).
  Исходный PDF лежит рядом; правьте `.md`, не PDF. Картинки поля — в `reglament/images/`.
- **Дрон (Обрик ROS 2, микродрон Whoop, legacy Clover)** → [`sverk/README.md`](sverk/README.md).
  Это не оглавление, а плотная выжимка: API, IP, пути `/dev`, АКБ, настройка PX4 через QGC,
  дефекты самой документации. Отвечает почти на всё быстрее, чем grep по страницам.
  Постраничный список — [`sverk/_INDEX.md`](sverk/_INDEX.md), `<раздел>/_ВСЁ.md` — раздел
  одним файлом для grep, `sverk/_raw/*.json` — сырые ответы API.
- **Ровер** → [`rover/README.md`](rover/README.md). В документации «Сверх» ровера нет вообще,
  это единственный источник. Разделы `01`–`08` по темам; `_pdf-polnaya-dokumentaciya.md` —
  архивная расшифровка PDF со **старой** раскладкой репозитория; поверх разделов `01`–`08`
  ей верить нельзя.
- **LLM/VLM, межагентная связь, боевые грабли PX4 и Nav2** → [`rover/04`](rover/04-agent-mcp-i-llm.md),
  [`rover/05`](rover/05-fleet-mqtt-i-mezhagentnaya-svyaz.md) и [`openclaw/`](openclaw/README.md).
- **Координаты, маркеры, привязка кадра к полю** → [`field-map/README.md`](field-map/README.md)
  и [`zmeyka.md`](zmeyka.md).

## Что здесь не является истиной

- **`openclaw/` — чужой проект без лицензии**, а регламент запрещает обмен данными между
  командами. Читать как источник боевого опыта можно, переносить архитектуру целиком — нет.
  Их калибровка поля частично неверна (id и размер маркера), см. [`field-map/`](field-map/README.md).
- **`rover/_pdf-polnaya-dokumentaciya.md`** описывает раскладку, которой больше нет.
- **`sverk/`** содержит собственные ошибки — они перечислены в разделе «Замеченные проблемы
  в документации» в конце [`sverk/README.md`](sverk/README.md).
- **`field-map/`** снята 2026-07-27, обновлена 2026-07-28 (маркеры 62 и 7 подняты на 0,31 м —
  поле разновысотное) и на железе не проверялась.

Процедуры обновления выгрузок — в `sverk/README.md` и в конце `rover/README.md`;
краткая версия и грабли этой машины (нет `poppler`, `urllib` падает на SSL) — в `../CLAUDE.md`.
