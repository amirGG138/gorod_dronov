# База знаний


В этом разделе собраны справочные материалы для углублённой работы с Обриком: настройка программного окружения, примеры кода, документация по дополнительному оборудованию и сетевым подключениям.


Раздел рассчитан на пользователей, которые уже выполнили базовую настройку и первый полёт и хотят расширить возможности дрона или разобраться в деталях работы системы.
