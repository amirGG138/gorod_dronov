# Настройка полётного контроллера


Во время настройки полётного контроллера ваш компьютер будет подключён к Wi-Fi сети бортового компьютера — доступа к интернету не будет. Убедитесь заранее, что выполнен раздел [Настройка](/learn/clover-2/preinstallation) — программа QGC и файл с параметрами уже скачаны.

-

Убедитесь, что SD-карта вставлена

-

Убедитесь, что Обрик подключён по Wi-Fi (см. раздел [Подключение к QGroundControl](/learn/clover-2/connect-wi-fi))


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F2.png&sig=691ac852f75f23ee901c49aecd1698baea922fb87d887c76d20776f31b70e5f4)


-

Нажмите на **логотип QGC** в левом верхнем углу


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F3.png&sig=512a6dc35c189f51c0e2be61ad1868a379fe24d29ffa1d44e8fafcfe144909b7)


-

Выберите **Vehicle Configuration**


![](https://api.edu.sverk.tech/api/courses/import/github/asset?owner=SeliverstovaE&repo=clover_sverk&ref=master&path=docs%2Fassets%2F1sverk%2Fsetup_flight_controller%2F4.png&sig=f10e5d680c93134f0b88cfd94e66c1181ef41b1ed83f96f77d1711d167be9793)



Вкладка **Summary** содержит информацию о выбранных настройках и состоянии систем: зелёный маркер — система настроена, красный — не настроена.
