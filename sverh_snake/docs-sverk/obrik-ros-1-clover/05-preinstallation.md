# Предустановка необходимых программ и файлов


## Шаг 1. Установка программного обеспечения


Для дальнейшей настройки и работы с Обриком необходимо скачать и установить следующие программы:

-

**Balena Etcher** — программа для записи образа на SD-карту бортового компьютера. Скачайте с [официального сайта](https://etcher.balena.io/#download-etcher) (доступна для Windows/Linux/macOS).

-

**QGroundControl (QGC)** — программа для настройки и калибровки полётного контроллера. Скачайте с [официального сайта](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/getting_started/download_and_install.html) (доступна для Windows/Linux/macOS). При запросе **согласитесь на установку** дополнительных драйверов.


## Шаг 2. Скачивание файлов для настройки Обрика


*Создайте на рабочем столе папку, например «Обрик», и сохраняйте все файлы в неё.*

-

[Образ бортового компьютера](https://disk.360.yandex.ru/d/ET9fV_EPzix4Qg) — включает всё необходимое ПО для работы с Обриком и программирования автономных полётов.

-

[Файл с параметрами полётного контроллера](https://drive.google.com/file/d/1oXUSC6eFqQdOReyK6MX7AvGgaQyNHEUr/view?usp=drive_link).

-

Генератор карт ArUco-меток для [Windows](https://drive.google.com/file/d/1awWAnfIA4tSUI5ZMT71OtbVWeySTOAlM/view?usp=drive_link) / [macOS](https://drive.google.com/file/d/1StvdPBVqm_7pMmgvg7h_3eX_NKunb3TV/view?usp=drive_link).


>

**Note** Ссылки на файлы могут обновляться. Если какая-то из них не работает — напишите в чат поддержки [@sverk_support](https://t.me/sverk_support).
