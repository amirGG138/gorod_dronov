# Прошивка PX4


>

**Примечание** Эта инструкция рассчитана на **Linux (Ubuntu)**.


Инструкция по обновлению прошивки полётного контроллера Обрика: режим DFU, загрузчик, пошаговая прошивка.


---


## Что такое прошивка и зачем её обновлять


Полётный контроллер Обрика работает на прошивке PX4. Прошивка — это программа, которая живёт прямо внутри чипа контроллера и управляет всем: читает датчики, управляет моторами, обрабатывает команды с аппаратуры управления.


Иногда нужно установить другую версию PX4: например, если вышло важное исправление ошибки или нужна версия с новыми функциями.


Контроллер Обрика построен на чипе STM32. Он поставляется с заводским загрузчиком, который не умеет работать с PX4. Сначала нужно заменить заводской загрузчик на загрузчик PX4, и только потом прошивать саму программу полёта.


Режим DFU (Direct Firmware Update) — режим чипа, в котором прошивку можно записать прямо в его память через USB, без посредников.


---


## Шаг 1. Подготовка репозитория PX4


Откройте терминал и выполните команды:


```
git clone https://github.com/PX4/PX4-Autopilot.git --recursive
cd PX4-Autopilot
git checkout v1.15.4
git submodule update --recursive
make distclean
bash ./Tools/setup/ubuntu.sh --no-sim-tools

```


Что здесь происходит: вы скачиваете исходный код PX4 версии v1.15.4, переключаетесь на эту версию, обновляете все зависимые библиотеки, очищаете старые файлы сборки и устанавливаете нужные инструменты.


Это займёт несколько минут: репозиторий большой.


---


## Шаг 2. Перевод контроллера в режим DFU


Режим DFU включается так:

- Полностью отключите плату от питания.
- Нажмите и удерживайте кнопку **BOOT** на плате.
- Подключите плату к компьютеру по USB (кнопку продолжайте держать).
- Убедитесь, что плата вошла в DFU-режим: светодиод должен гореть красным без мигания.

Теперь чип готов принять новый загрузчик.


---


## Шаг 3. Прошивка загрузчика PX4


```
make matek_h743-slim_bootloader
dfu-util -a 0 --dfuse-address 0x08000000 -D build/matek_h743-slim_bootloader/matek_h743-slim_bootloader.bin

```


Первая команда собирает загрузчик из исходного кода. Вторая записывает его в чип через утилиту `dfu-util`.


После успешной записи `dfu-util` напишет о завершении. Тогда отключите плату от USB и подключите снова, **не нажимая** кнопку BOOT. Если всё прошло успешно, светодиоды начнут мигать в штатном режиме, красный DFU-индикатор погаснет.


---


## Шаг 4. Прошивка основной программы PX4


Загрузчик PX4 активен несколько секунд после включения платы. За это время нужно успеть передать прошивку. Поэтому сначала запустите команду загрузки, а потом сразу подключите плату:


```
make matek_h743-slim_default
python3 Tools/px_uploader.py --port /dev/ttyACM0 build/matek_h743-slim_default/matek_h743-slim_default.px4

```


>

**Примечание** Если путь `/dev/ttyACM0` не подходит, уточните командой `ls /dev/tty*` — посмотрите, какие устройства появились после подключения платы.


После успешной прошивки PX4 загрузится. При подключении по USB к QGroundControl начнут появляться диагностические сообщения.
