# Бортовой компьютер Обрика


Бортовой компьютер — одноплатный компьютер на Linux, на котором работают Docker, ROS 2 и программы на Python. Он связан с полётным контроллером PX4 по UART и принимает команды от вас по Wi-Fi.


## Из чего состоит бортовой компьютер


Бортовой компьютер Обрика собран из двух частей:


![](https://api.edu.sverk.tech/api/courses/import/gitlab/asset?origin=https%3A%2F%2Fgit.sverk.io&project=SES%2Fdocs&ref=main&path=obrik%2Fros2%2Fassets%2Fdiagrams%2Fonboard-composition.svg&sig=c79f3c468f5677f8d32343eb50ab5f2aad4efbb8ad0102fcd7af98d448d7a1e6)



>

**Примечание** Из двух частей (вычислительный модуль + плата расширения) состоят только compute-модули — **Raspberry Pi CM5** и **Radxa CM5**: сам модуль не имеет разъёмов и устанавливается на несущую плату. Полноразмерные одноплатные компьютеры (**Orange Pi 5 Pro**, **Orange Pi Zero 3W**, **RDK X3**) самодостаточны — разъёмы у них уже на самой плате, отдельная плата расширения не нужна.


## Что умеет плата расширения


Плата расширения специально сделана под Обрик: она не больше самого модуля (55 x 40 мм) и весит около 20 граммов. Это важно для дрона: каждый грамм на счету. На плате есть несколько разъёмов для подключения оборудования:

|  Разъём |  Для чего нужен |
|  USB 3.1 (Type-C, до 5 Гбит/с) |  Лидары, быстрые камеры |
|  Ethernet (100 Мбит/с) |  Надёжная связь по кабелю |
|  2x MIPI CSI (2-lane) |  Две камеры одновременно (стереозрение) |
|  2x USB 2.0 |  Периферия: мышь, модули |
|  40-pin GPIO (JST-SH) |  Датчики, светодиодные ленты, сервоприводы |
