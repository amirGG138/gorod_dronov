# Автономный полёт: Python API


Автономное управление микродроном реализуется через Python-модуль `simple_offboard_py`. Программы запускаются прямо на бортовом компьютере через SSH.


>

**Внимание** Во время автономного полёта держите аппаратуру управления в руках. При нештатной ситуации переключите **SB** в режим **Position** для перехвата управления, затем посадите дрон вручную.


## Быстрый старт


Подключитесь к микродрону по SSH и создайте файл программы:


```
nano flight.py

```


Минимальный пример — взлёт, зависание, посадка:


```
from simple_offboard_py import SimpleOffboard, Frame

drone = SimpleOffboard()

drone.takeoff(0.7)
print("Взлетел")

drone.land()
print("Сел")

```


Запустите:


```
python3 flight.py

```


>

**Подсказка** Перед запуском убедитесь, что прошла [предполётная проверка](/learn/whoop/check) и микродрон находится в режиме [POSITION](/learn/whoop/manual-flight-position).


## Системы координат


Все методы навигации принимают параметр `frame` — систему координат.


### Frame.BODY_NED


Координаты относительно **текущего положения и курса** дрона.

- X — вперёд по носу, Y — вправо, Z — вниз.
- Удобна для команд «лети вперёд на 1 м» без привязки к карте.

```
# Лететь вперёд на 1 м относительно текущего курса
drone.navigate(1.0, 0.0, -0.7, frame=Frame.BODY_NED, yaw=0.0)

```


### Frame.LOCAL_NED


Координаты относительно **точки взлёта**, оси не вращаются.

- X — на север, Y — на восток, Z — вниз.
- Удобна для навигации по точкам и планирования траекторий.

```
# Лететь в точку (1, 1) на высоту 0.7 м от точки взлёта
drone.navigate(1.0, 1.0, -0.7, frame=Frame.LOCAL_NED, yaw=0.0)

```


>

**Примечание** Ось Z направлена **вниз** — высота 0.7 м над землёй это `z = -0.7`.


## Взлёт и посадка


### takeoff


```
drone.takeoff(height: float = 1.0) -> bool

```


Взлетает на заданную высоту и зависает. Автоматически переводит контроллер в offboard-режим и включает моторы.


Возвращает `True`, если высота достигнута, `False` при превышении тайм-аута.


```
drone.takeoff(0.7)
print("Взлетел")

```


### land


```
drone.land()

```


Посадка. Блокирует выполнение до касания земли, после чего автоматически выключает моторы.


## Навигация


### navigate — полёт к точке


```
drone.navigate(
    x: float,
    y: float,
    z: float,
    frame: Frame = Frame.LOCAL_NED,
    yaw: float | None = None,
    yaw_rate: float | None = None,
    tolerance: float = 0.1,
    time_limit: float = 10.0,
) -> bool

```


Перемещает дрон к заданной точке и ждёт прибытия. Возвращает `True`, если добрался, `False` при превышении `time_limit`.


**Параметры:**

- `x, y, z` — координаты цели.
- `frame` — система координат.
- `tolerance` — радиус «достиг цели» в метрах (по умолчанию 0.1).
- `time_limit` — максимальное время ожидания в секундах (по умолчанию 10.0).
- `yaw` — курс в радианах; `0.0` — смотреть на север (LOCAL_NED) или вперёд (BODY_NED).
- `yaw_rate` — угловая скорость по рысканью.

>

**Внимание** Нужно задать ровно один из параметров `yaw` или `yaw_rate`. Если оба `None` — команда будет проигнорирована.


### set_velocity — управление по скорости


```
drone.set_velocity(
    vx: float,
    vy: float,
    vz: float,
    frame: Frame = Frame.BODY_NED,
    yaw: float | None = None,
    yaw_rate: float = 0.0,
)

```


Задаёт скорость полёта. Не блокирует выполнение — дрон летит, пока не получит другую команду.


```
# Лететь вперёд на 1.2 м/с
drone.set_velocity(1.2, 0.0, 0.0, Frame.BODY_NED, yaw=0.0)

```


### set_position — непрерывное удержание точки


```
drone.set_position(
    x: float,
    y: float,
    z: float,
    frame: Frame,
    yaw: float | None = None,
    yaw_rate: float | None = None,
)

```


Публикует целевую позицию без ожидания прибытия. Используйте в цикле, когда цель постоянно обновляется (например, слежение за объектом).


## Получение данных


### get_position — текущее положение


```
x, y, z, roll, pitch, yaw = drone.get_position()

```


Возвращает координаты в локальной системе и углы Эйлера в радианах.


### get_detections — обнаруженные объекты


```
for det in drone.get_detections():
    print(det.label, det.score, det.x1, det.y1, det.x2, det.y2)

```


Возвращает список объектов, найденных системой компьютерного зрения. Поля каждого объекта:

- `label` — название класса (например, `"balloon"`).
- `score` — уверенность от 0.0 до 1.0.
- `x1, y1` — левый верхний угол прямоугольника (пиксели).
- `x2, y2` — правый нижний угол прямоугольника (пиксели).
- `class_id` — числовой ID класса.

## Ручное включение моторов


`takeoff()` включает моторы автоматически. Если нужно управлять этим вручную:


```
drone.arm()           # включить моторы
drone.disarm()        # выключить моторы
drone.set_flight_mode(0)  # перевести в offboard-режим

```


>

**Подсказка** Типичный порядок ручного запуска: опубликовать сетпоинты → `set_flight_mode()` → `arm()`.
